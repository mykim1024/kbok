# KBO 기록 해석 서비스

> 숫자만 있는 KBO 기록을 **리그 순위와 평균으로 해석**해, 야구 입문자도 선수의 수준을 바로 알 수 있게 만드는 서비스

**상태: 진행 중** — API 완성, 화면·배포 진행 중

<br/>

## 왜 만들었나

야구를 보기 시작했을 때, 기록실의 숫자만으로는 "OPS 0.901이 잘한 건지" 감이 오지 않았습니다. KBO 기록실은 모든 숫자를 보여주지만, 그 숫자가 리그에서 어느 정도인지는 알려주지 않습니다.
그래서 KBOK은 기록 하나하나를 리그 순위와 평균으로 해석해서 보여주는 것부터 시작했습니다.

다음으로는 선수끼리 비교하는 기능과, 실제 기록으로 타자와 투수의 한 타석 대결을 굴려보는 미니게임을 만들 예정입니다. 장기적으로는 이렇게 쌓은 데이터를 바탕으로, 팬이 직접 감독이 되어 라인업과 투수 운용을 정해보는 게임을 별도 프로젝트로 만드는 것이 목표입니다.

<br/>

## 주요 기능

| API | 설명 |
|---|---|
| `GET /api/batters?season=` | 타자 목록. 팀·이름·규정타석 검색, OPS·타율·홈런 정렬, 페이징 |
| `GET /api/batters/{kboPlayerId}?season=` | 타자 상세. 기록별 순위·상위 %·리그 평균 |
| `GET /api/pitchers?season=` | 투수 목록. 선발/불펜 필터, ERA·WHIP·승·탈삼진·세이브·홀드 정렬, 페이징 |
| `GET /api/pitchers/{kboPlayerId}?season=` | 투수 상세. 기록별 순위·상위 %·리그 평균 |
| `GET /api/players/popular` | 오늘 많이 본 선수 TOP 10 |

## 순위 규칙

### 1. 기록마다 좋은 방향과 비교 대상이 다릅니다

| 구분 | 기록 | 좋은 방향 | 순위 비교 대상 | 리그 평균 |
|---|---|---|---|---|
| 타자 비율 기록 | 타율 · 출루율 · 장타율 · OPS | 높을수록 | 규정타석(446타석)을 채운 타자 | 표시 |
| 타자 누적 기록 | 홈런 | 높을수록 | 그 시즌 전체 타자 | 표시 안 함 |
| 투수 비율 기록 | ERA · WHIP | **낮을수록** | 규정이닝(144이닝)을 채운 투수 | 표시 |
| 투수 누적 기록 | 승 · 탈삼진 · 세이브 · 홀드 | 높을수록 | 그 시즌 전체 투수 | 표시 안 함 |

- 비율 기록은 본인이 규정을 채웠을 때만 순위를 매깁니다. 규정 미달이면 값과 리그 평균만 보여줍니다.
- 누적 기록은 규정과 상관없이 순위를 매기되, 값이 0이면 순위를 매기지 않습니다. (예: 선발 투수의 홀드 0개)

### 2. 순위

**순위 = 1 + 나보다 잘한 선수 수.** 동점은 같은 순위이고, 다음 순위는 그만큼 건너뜁니다.

| OPS | 0.950 | 0.900 | 0.900 | 0.800 |
|---|---|---|---|---|
| 순위 | 1위 | 2위 | 2위 | 4위 |

ERA처럼 낮을수록 좋은 기록은 "나보다 낮은 선수 수"를 셉니다.

### 3. 상위 %

**상위 % = 순위 ÷ 비교 인원 × 100, 소수점 올림.**
예: 49명 중 1위 → 2.04% → **상위 3%**

### 4. 리그 평균

선수별 기록의 평균이 아니라, 그 시즌 **전체 선수의 합계**로 계산합니다. (규정 미달 선수 포함)

| 기록 | 계산 |
|---|---|
| 타율 | 전체 안타 ÷ 전체 타수 |
| 출루율 | (안타 + 볼넷 + 사구) ÷ (타수 + 볼넷 + 사구 + 희생플라이) |
| 장타율 | 전체 루타 ÷ 전체 타수 |
| OPS | 출루율 + 장타율 |
| ERA | 전체 자책점 × 27 ÷ 전체 아웃카운트 |
| WHIP | (전체 볼넷 + 전체 피안타) × 3 ÷ 전체 아웃카운트 |

<br/>

## 설계 결정

- **공식에 없는 순위는 만들지 않음**: 비율 기록(타율·ERA 등)은 규정 채운 선수끼리, 누적 기록(홈런·세이브 등)은 전체 선수끼리 비교. 시즌 합계 데이터라 선발/불펜 역할별 순위는 만들지 않음
- **리그 평균은 합계로 계산**: 선수별 평균의 평균이 아니라 전체 안타 ÷ 전체 타수. 이닝은 아웃카운트로 저장해 반올림 오차 방지
- **수집 후 자동 검증**: 총 인원·페이지 범위·출처 간 인원을 비교해 누락 감지 (첫 실행에서 명단 5명 누락 발견)
- **Redis 장애 격리**: 조회수 증가 실패 시 상세 조회는 정상 응답, TOP 10은 503, 깨진 값은 건너뜀

## 실행 방법

```bash
# 1. PostgreSQL, Redis 실행
docker run -d --name kbok-postgres -e POSTGRES_DB=kbok -e POSTGRES_USER=kbok -e POSTGRES_PASSWORD=[비밀번호] -p 5432:5432 postgres:16
docker run -d --name kbok-redis -p 6379:6379 redis:7.4

# 2. DB 계정 설정: src/main/resources/application-local.properties
spring.datasource.username=kbok
spring.datasource.password=[비밀번호]

# 3. 실행 (http://localhost:8081)
./gradlew bootRun

# 4. 데이터 수집 (10개 구단)
curl -X POST "http://localhost:8081/admin/crawl/all?season=2026"
```

## 알려진 한계

- **트레이드 선수**: KBO가 시즌 기록을 마지막 소속팀으로 합쳐 제공해, 팀별 기록으로 나눌 수 없습니다.
- **선발/불펜 역할별 기록**: 시즌 합계만 제공돼 역할별로 나눌 수 없습니다. 목록의 선발/불펜 필터는 선발 등판 비율 50% 기준의 참고용 분류입니다.
- **규정타석·규정이닝**: 144경기 기준 고정값(446타석·144이닝)입니다. 시즌 중에는 팀 경기 수 기준으로 계산해야 합니다.
- **선수 프로필**: 기록에서만 확인된 선수는 생년월일·포지션 등 프로필이 비어 있습니다.
- **명단 변경**: 명단에서 빠진 선수를 비활성화하지 않습니다.
- **수집 API**: 현재 인증이 없습니다. 배포 전 보완 예정입니다.
